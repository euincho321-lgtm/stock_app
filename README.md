# 조성원내과- 처방전

외래 환자 정보를 입력하면 AI에 바로 붙여 넣을 수 있는 구조화된 프롬프트를 생성하는 정적 웹사이트입니다.

## 온라인 주소

GitHub Pages 배포 후 아래 주소에서 접속할 수 있습니다.

- https://euincho321-lgtm.github.io/stock_app/

## 포함 기능

- 환자 정보 입력 폼
- 문진 질문/감별진단/추가 검사/처방 정리 프롬프트 생성
- 예시 자동 채우기
- 프롬프트 복사
- 브라우저 로컬 저장

## 주의

이 사이트는 의료진 판단을 보조하기 위한 프롬프트 생성 도구입니다.
최종 진단과 처방은 반드시 환자의 병력, 활력징후, 진찰, 검사 결과, 금기사항, 임신 여부, 복용약, 기저질환을 포함해 직접 판단해야 합니다.
